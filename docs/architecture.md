# ResearchLens – System Architecture

## 1. Overview

ResearchLens is a trustworthy academic research assistant
based on Information Retrieval and Retrieval-Augmented Generation.

## 2. Core Modules

### 2.1. Ingestion
Collects academic papers and extracts structured content.

### 2.2. Retrieval
Implements traditional and neural information retrieval methods.

### 2.3. RAG
Constructs evidence context and generates answers.

### 2.4. Truth Reader
Extracts claims and verifies them against retrieved evidence.

### 2.5. Evaluation
Measures retrieval effectiveness and answer reliability.

## 3. Design Principles

- Modular architecture.
- Reproducible experiments.
- Evidence-grounded generation.
- Source traceability.
- Model independence.
- Reproducible evaluation.
